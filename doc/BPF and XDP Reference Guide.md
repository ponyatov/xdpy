# [[eBPF]] and [[XDP]] Reference Guide

https://docs.cilium.io/en/stable/reference-guides/bpf/index.html

[[eBPF|BPF]] is a highly flexible and efficient [[vm/Virtual Machine|Virtual Machine]]-like construct in the [[Linux/kernel]] allowing to execute [[vm/bytecode|bytecode]] at various hook points in a safe manner. It is used in a number of Linux kernel subsystems, most prominently networking, tracing and security (e.g. sandboxing).
